## 🚀 How to Use

1. Open the JSON file you need
2. Replace the placeholder values with your real data
3. Copy the entire code
4. Paste it inside your page:

```html
<script type="application/ld+json">
  ...paste here...
</script>
```

5. Test with [Google Rich Results Test](https://search.google.com/test/rich-results)

## 📁 Available Snippets

| File | Schema Type | Best for |
|------|-------------|----------|
| [`LocalBusiness.json`](LocalBusiness.json) | LocalBusiness | Local service businesses, shops, clinics |
| [`FAQPage.json`](FAQPage.json) | FAQPage | Any page with FAQs |
| [`Article.json`](Article.json) | Article | Blog posts & articles |

---

## ✅ Important Notes

- Always validate your schema before publishing
- Keep the JSON structure exact (commas, brackets, quotes)
- For LocalBusiness → make sure NAP matches your Google Business Profile
- You can combine multiple schemas on the same page

---

## 💡 Pro Tip

Add FAQ schema on service pages and blog posts — it often helps win rich results and more visibility in search.
